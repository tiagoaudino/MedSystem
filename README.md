# MedSystem
MedSystem 🩺

Sistema clínico desenvolvido em Java para gerenciamento de pacientes e consultas médicas.

O projeto foi desenvolvido com o objetivo de praticar conceitos de Programação Orientada a Objetos, arrays de objetos, métodos, estruturas de repetição, condicionais e regras de negócio.

📌 Funcionalidades
Cadastro de pacientes
Listagem de pacientes
Busca de pacientes pelo nome
Cadastro de consultas
Associação de consultas aos pacientes
Listagem de consultas
Limite de 10 consultas por dia
Verificação de conflitos de data e horário
Validação de pacientes cadastrados

🛠️ Tecnologias
-Java
-Programação Orientada a Objetos
-Arrays de objetos

Este projeto está em sua versão 1.0 e poderá receber novas funcionalidades futuramente
